Privacy policy

Clip Uploader · Last updated 20 November 2026

Clip Uploader is a personal tool used only by its owner, on the owner's own computer, to upload videos to the owner's own YouTube channel.

Google data it accesses

  • Permission to upload YouTube videos (the youtube.upload scope), so it can post clips to the channel the owner picks when signing in.
  • Read-only access to the channel's name (the youtube.readonly scope), used once at sign-in to show which channel uploads will go to.

It does not read, change or delete existing videos, comments, subscribers, analytics or any other account data.

How the data is stored and used

  • The sign-in token from Google is stored only in a file on the owner's computer. It is never sent anywhere except to Google when uploading.
  • No data is collected, sold, shared with third parties or used for advertising.
  • There are no analytics or tracking.

Clip Uploader's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the computer also removes the tool's access.
